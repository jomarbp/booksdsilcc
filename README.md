# Biblioteca Académica DSI

Sitio web estático del **Programa de Estudios de Desarrollo de Sistemas de Información** del **IESTP Luciano Castillo Colonna**.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube a la raíz del repositorio estos archivos: `index.html`, `styles.css`, `app.js` y `.nojekyll`.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main`, la carpeta `/ (root)` y presiona **Save**.
6. GitHub mostrará la dirección pública cuando termine la publicación.

No requiere Node.js, compilación, dependencias ni base de datos. Los filtros y la búsqueda funcionan completamente en el navegador.
